# ChatTweaks Mod for Minecraft 1.21.11 (Fabric)

## Installation

1. Make sure you have **Minecraft 1.21.11** and **Fabric Loader** installed. (also fabric api needed!)
2. Download the mod `ChatTweaks 1.21.11fb.jar` file.
3. Place the `ChatTweaks 1.21.11fb.jar` file into your `mods` folder (located in your Minecraft game directory). Create the `mods` folder if it doesn't exist.
4. Launch the game using the **Fabric** profile.
5. The mod is now active. Enjoy!

## How to Use

- **Copy Messages:** Press and **hold** the `Ctrl` key. While holding it, **Right-Click** on any chat message to copy its text to your clipboard.
- **View History:** Open the chat and **scroll your mouse wheel** up/down to view up to 16,000 previous messages.
- **Portal Chat:** Simply press your chat key while standing inside a Nether or End portal to type normally.

## Changing the Chat Keybind (Optional)

To change the default Chat key:

- Go to `Settings` → `Options` → `Controls` → `Key Binds`
- Find the **Multiplayer** category
- Look for the Open Chat entry (`T` by default)
- Click on it and press your desired key

**Tip:** Your extensive chat history will persist seamlessly even if you switch servers or change dimensions.

Good luck! :P
